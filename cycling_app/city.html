実際の街を3Dで走りながら進めるライディングデュエル(家で遊ぶ用)

🏠 自宅を登録

Googleの3D(Googleマップの3Dと同じ写真の街)

料金がかからないように、この端末では 月450回・1日20回 で自動的に止めます(数えるのは「Googleの3Dで走り始めた回数」)。確実に止めるには、Google Cloud 側でも1日の上限を決めてください。

APIキーの取り方(5分)
  1. Google Cloud コンソールを開き、プロジェクトを作る(名前は何でもよい)。
  2. 「お支払い」で請求先アカウントを登録する(クレジットカードが必要。登録だけでは課金されません)。
  3. 「APIとサービス」→「ライブラリ」で Map Tiles API を探して「有効にする」。
  4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」。
  5. 作ったキーを開き、「アプリケーションの制限」をウェブサイトにして https://suzukijunya.github.io/* を追加。「APIの制限」は Map Tiles API だけにして保存。
  6. 上限を決める(大事): 「APIとサービス」→「Map Tiles API」→「割り当てとシステム上限」で、Photorealistic 3D Tiles の Root 〜 per day を 30 に下げる(30回×31日=930回で、月1,000回を超えません)。
  7. 「お支払い」→「予算とアラート」で、予算 100円 のアラートを作っておく(万一のときにメールが来ます)。
  8. キー(AIza… で始まる文字)を上の欄に貼る。

街の建物と道は OpenStreetMap の地図タイル(OpenFreeMap)から取ります。送るのは、出発と目的地の位置と、ルートが通る地図の区画(約2km四方)の番号だけです。一度取った街は端末に保存します。地面の航空写真は国土地理院の地図タイル、実物の建物は国土交通省の PLATEAU です(どちらも区画の番号だけを送ります)。
