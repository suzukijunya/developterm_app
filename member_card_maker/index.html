📋 Googleフォームで集めてまとめて作る
  1. フォームを作る(最初の1回だけ): Apps Script で新しいプロジェクトを開き、して貼り付け →「createCardForms」を実行。カード投稿フォーム・世界観メモ投稿フォーム・回答スプレッドシートができます。
  2. 社内に回答してもらう: 実行ログに出たフォームのURLを共有。必須は「カード種類」と「元ネタ」だけで、書かなかった項目はAIが考えます。
  3. 回答を読み込む: 回答スプレッドシートのURLを入れて「回答を読み込む」(共有を「リンクを知っている全員」にしておく)。共有したくない場合は、シートを全選択してコピーし下の欄に貼り付け。何度読み込んでも、読み込み済みの回答は飛ばします。
  4. 空欄をAIで埋める → 一覧から1枚ずつイラストを入れて確認 →「全カードをPNG保存」

③ イラスト

プレビューのイラストをドラッグで位置調整、ホイールで拡大縮小できます。作成済みのトレカ画像(枠つき)を入れたときは「トレカ画像からイラスト部分だけ使う」で枠が二重になりません。

画像生成AI用プロンプト(写真 → カードのイラスト)

本人の写真と一緒に ChatGPT などの画像生成AIに渡すと、枠・文字なしのイラストが作れます。できた画像を上の「写真・イラスト」に入れてください。文字はこのツールが描くので文字化けしません。

④ テキスト

改行で段落を分けます。「①：」で始まる行は2行目以降が字下げされます。「---」だけの行は区切り線になります。長いと文字が自動で小さくなります。
