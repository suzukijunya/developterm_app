# 社内トレカ 入力フォーマット

`member_card_maker/index.html` をブラウザで開くと使えます(サーバー不要。GitHub Pages ならそのまま公開可)。
モンスター・魔法・罠カードを、1枚ずつでも、Google フォームで社内から集めてまとめてでも作れます。

## 必要な情報

**最低限は「カード種類」と「元ネタ」の2つだけ。** 残りはAIが考えます。

| 区分 | 項目 | 何を書くか |
|---|---|---|
| 必須 | カード種類 | 効果モンスター / 通常・融合・儀式・シンクロ・エクシーズモンスター / 魔法カード / 罠カード |
| 必須 | 元ネタ | モデルになる人の名前、社内用語、出来事、商品・案件など |
| あると面白くなる | 口癖・名ゼリフ / エピソード / 一緒に登場させたい人・モノ | 効果テキストのネタ。カード同士をつなげたいときは他のカード名を「」で書く |
| 人のとき | 部署 / 役職・担当 / 特徴・得意なこと | 二つ名・種族・ATK/DEF を考える材料 |
| 魔法・罠のとき | 魔法・罠の種類 | 魔法: 通常/永続/装備/速攻/フィールド/儀式、罠: 通常/永続/カウンター(空欄なら通常) |
| 決めたい場合だけ | カード名 / 属性 / レベル / 種族 / 効果テキスト / ATK / DEF | 書いた項目はそのまま使い、空欄の項目だけAIが合わせて考える |
| 任意 | カードコード / イラスト画像ファイル名 / イラストの光 / 雰囲気 | カードコードは空欄なら WB-001 から連番 |

### どんなカードにするか(元ネタの例)

| カード種類 | 向いている元ネタ | 例 |
|---|---|---|
| 効果モンスター | 社員(1人1枚) | 財務統括魔導士スズキ |
| 融合・シンクロ・エクシーズ | 名コンビ、チーム、部署 | 「スズキ」＋「ヨナハ」の財務税務タッグ |
| 魔法カード | 社内用語、決め台詞、便利な道具、イベント | 法務確認(速攻)、月末締め(フィールド)、電卓(装備) |
| 罠カード | 相手を止める・跳ね返す出来事 | リターン請求(カウンター)、稟議差し戻し(永続) |

### 世界観メモ(おすすめ)

ウィーブレインの社内用語・人物・出来事を「用語 / 種類 / 説明」で書いておくと、**すべてのカードのAI生成で使われ**、
カード同士の効果が「グレー金融」「法務確認」のようにつながります。
画面の「Googleフォームで集めてまとめて作る → ウィーブレインの世界観メモ」に書くか、世界観メモ投稿フォームで社内から集めます。

## Google フォームで集めて、まとめて作る

### 1. フォームを作る(最初の1回だけ・5分)

1. [Apps Script](https://script.google.com/home/projects/create) で新しいプロジェクトを開く
2. [`google_form/create_form.gs`](google_form/create_form.gs) の中身を全部貼り付けて保存
   (ツール画面の「フォーム作成スクリプトをコピー」でもコピーできます)
3. 関数の選択欄で `createCardForms` を選んで「実行」→ Google アカウントの権限を許可
4. 実行ログに次の URL が出る
   - **カード投稿フォーム**(社内に共有する)
   - **世界観メモ投稿フォーム**(社内用語・人物・出来事を集める。任意)
   - **回答スプレッドシート**(シート「カード回答」「世界観メモ回答」に回答がたまる)

カード投稿フォームは、最初に「カード種類」を選ぶと、モンスター / 魔法 / 罠それぞれの質問だけが出ます。

| セクション | 質問 |
|---|---|
| 最初 | 投稿者、カード種類(必須) |
| モンスター | 元ネタ(必須)、部署、役職・担当、特徴・得意なこと、口癖・名ゼリフ、エピソード、一緒に登場させたい人・モノ、雰囲気、カード名、属性、レベル、種族、効果テキスト、ATK、DEF |
| 魔法 | 魔法の種類(通常/永続/装備/速攻/フィールド/儀式)、元ネタ(必須)、特徴、エピソード、一緒に登場させたい人・モノ、雰囲気、カード名、効果テキスト |
| 罠 | 罠の種類(通常/永続/カウンター)、元ネタ(必須)、特徴、エピソード、一緒に登場させたい人・モノ、雰囲気、カード名、効果テキスト |
| 最後 | イラストの光、メモ |

カード名・属性・レベル・種族・効果・ATK/DEF は任意で、空欄や「おまかせ」は AI が考えます。
質問の**タイトル**はツールが読み込むときの列名なので変えないでください(説明文は自由に変えて OK。質問を足しても、知らない列は無視されます)。

### 2. 回答を読み込んでカードにする

1. ツールの「📋 Googleフォームで集めてまとめて作る」を開く
2. 次のどちらかで読み込む(何度読み込んでも、読み込み済みの回答は飛ばされます)
   - **URL で読み込む**: 回答スプレッドシートの共有を「リンクを知っている全員(閲覧者)」にして、URL を入れて「回答を読み込む」。
     「カード回答」と「世界観メモ回答」の両方が読み込まれます
   - **コピペで読み込む(共有しなくてよい)**: 「カード回答」シートで Ctrl+A → Ctrl+C し、貼り付け欄に Ctrl+V →「貼り付けた回答を読み込む」。
     「世界観メモ回答」シートも同じように貼ると世界観メモに入ります
3. 「空欄をAIでまとめて埋める」(Claude API キーが必要)
   - キーがない場合: 「空欄を埋めてもらうチャットAI用プロンプトをコピー」→ ChatGPT / Claude に貼り、続けて回答シートの内容を貼る →
     返ってきた表を貼り付け欄から読み込む
4. 一覧から1枚ずつイラストを入れて確認・修正し、「全カードをPNG保存」

スプレッドシートの「ファイル → ダウンロード → CSV」で落とした CSV も読み込めます。

## 1枚ずつ作る

1. **① 元ネタ**でカード種類を選び、元ネタ・口癖・エピソードなどを入れる
2. **AIでカード文面を作る**(キーがなければ「チャットAI用プロンプトをコピー」→ 返ってきた JSON を貼って反映)
3. **③ イラスト**に写真や画像を入れる。「画像生成AI用プロンプト」をコピーして画像生成AIに渡すと、枠・文字なしのイラストが作れる
   - 枠つきの完成トレカ画像を入れたときは「トレカ画像からイラスト部分だけ使う」
4. **PNGで保存**(2048×2880px)

カードはブラウザに自動保存されます。別のPCへ移すときやチームで共有するときは「全カードをJSON保存」→「JSON読み込み」(世界観メモも一緒に保存されます)。

## 作ったカードでデュエルする

トレカメーカー上部の「⚔ このカードでデュエル」(`duel/index.html`)で、作ったカードのデッキで CPU と対戦できます。
マスターデュエルを簡略化したルールです(LP 8000・手札5枚・通常召喚1回・生け贄召喚・攻撃/守備表示・魔法/罠・罠の割り込み)。

- デッキ: トレカメーカーに保存されているカードで自動で作成(1種類3枚まで、少ないときは多めに入れて30枚)。「全カードをJSON保存」したファイルも読み込めます
- 生け贄: レベル7〜9は1体、10以上は2体。自分の場が空なら上級モンスターも「妥協召喚」(攻撃力半分)で出せます
- **ゲーム効果**: 効果テキストは自由な文章なので、キーワード(ドロー・破壊・無効・特殊召喚・ダメージ・回復・攻撃力など)と魔法・罠の種類から、
  下のどれか1つを自動で割り当てます。カードを選ぶと画面左に表示されます

| 種類 | ゲーム効果 |
|---|---|
| モンスター | 召喚時1枚ドロー / 召喚時500ダメージ / 召喚時1000回復 / 他の味方の攻撃力+300 / 召喚時に相手モンスター1体破壊(レベル7以上)/ 手札からレベル4以下を特殊召喚 / 効果なし(通常モンスター) |
| 魔法 | 2枚ドロー / 相手モンスター1体破壊 / 相手の魔法・罠1枚破壊 / 800ダメージ / 1500回復 / 墓地から特殊召喚 / 装備(攻撃力+500)/ フィールド(味方+300・相手-100)/ 永続(味方+200) |
| 罠 | 攻撃を無効にしてバトル終了 / 攻撃モンスターを破壊 / 攻撃を無効にしてダメージ / 魔法の発動を無効(カウンター)/ 相手の攻撃力-300(永続) |

ファイル: `duel/engine.js`(ルール)、`duel/cpu.js`(CPU の判断)、`duel/ui.js`(画面・演出・効果音)

## JSON の項目(開発者向け)

1枚のカードは次の JSON です(「⑤ その他 → このカードのJSON」で確認・直接編集できます)。
複数枚まとめて読み込むときは `{"formatVersion": 1, "world": "世界観メモ", "cards": [ ... ]}` か配列にします。

```json
{
  "formatVersion": 1,
  "cardType": "spell",
  "subtype": "速攻",
  "name": "法務確認",
  "attribute": "魔",
  "customAttribute": { "text": "", "color": "#c6352a", "image": null },
  "level": 0,
  "tribe": "",
  "abilities": "",
  "effect": "①：相手が「グレー金融」を発動した時に発動できる。その発動を無効にし、自分はデッキから１枚ドローする。",
  "atk": "0",
  "def": "0",
  "cardCode": "WBSP-001",
  "copyright": "©2024 WB ARGO",
  "frameColor": "",
  "nameColor": "gold",
  "art": { "image": null, "zoom": 1, "x": 0, "y": 0, "effect": "blue", "intensity": 0.7, "fileName": "" },
  "member": {
    "realName": "法務チェック",
    "department": "",
    "role": "",
    "skills": "契約の穴を一瞬で見抜く",
    "personality": "",
    "episode": "スズキの得意技",
    "related": "「財務統括魔導士スズキ」",
    "tone": "かっこよく"
  },
  "autoFields": []
}
```

| 項目 | 内容 | 値 |
|---|---|---|
| `cardType` | カード種類(枠の色が変わる) | `normal` 通常 / `effect` 効果 / `ritual` 儀式 / `fusion` 融合 / `synchro` シンクロ / `xyz` エクシーズ / `spell` 魔法 / `trap` 罠 |
| `subtype` | 魔法・罠の種類(【魔法カード】の横のアイコン) | 魔法: `通常` `永続` `装備` `速攻` `フィールド` `儀式`、罠: `通常` `永続` `カウンター` |
| `name` | カード名。長いと自動で横に縮む | 文字列 |
| `attribute` | 右上の属性マーク | `光` `闇` `炎` `水` `風` `地` `神` `魔` `罠` `custom` |
| `customAttribute` | `attribute: "custom"` のときの中身。`image` に国旗などの画像を入れると画像が優先 | `text` 1〜2字 / `color` / `image` |
| `level` | 星の数(エクシーズは左から並ぶ)。魔法・罠では無視 | 0〜12 |
| `tribe` / `abilities` | 種族行「【CFO族／効果】」。`abilities` が空ならカード種類から自動 | 文字列 |
| `effect` | 効果テキスト。改行で段落、`①：` で始まる行はぶら下げ字下げ、`---` だけの行は区切り線。長いと自動で縮む | 文字列 |
| `atk` / `def` | 攻撃力・守備力。`?` も可。魔法・罠では無視 | 文字列 |
| `cardCode` / `copyright` | イラスト右下の番号 / 一番下の表記 | 文字列 |
| `frameColor` / `nameColor` | 枠の色の上書き / カード名の色 | `#rrggbb` / `gold` `white` `black` |
| `art` | イラストと位置(`x` `y` は枠の幅に対する割合)、光エフェクト、表から読み込んだときの画像ファイル名 | |
| `member` | AI が文面を考えるための元ネタ(カードには印刷されない) | `tone` は `かっこよく` `面白く` `かわいく` `渋く` |
| `autoFields` | フォームの回答から読み込んだとき空欄だった項目。「空欄をAIでまとめて埋める」でここだけ作られる | `name` `attribute` `level` `tribe` `effect` `atk` `def` |
| `responseKey` / `author` | フォームの回答の目印(二重読み込み防止)/ 投稿者 | 文字列 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `google_form/create_form.gs` | カード投稿フォーム・世界観メモ投稿フォーム・回答スプレッドシートを作る Apps Script |
| `js/card_format.js` | 上記フォーマットの定義・正規化、表の読み書き、AI向けプロンプト |
| `js/card_renderer.js` | JSON → canvas への描画(枠・星・属性・魔法罠アイコン・イラスト・テキスト組版) |
| `js/ai.js` | Claude API 呼び出し(キーはブラウザ内のみに保存) |
| `js/app.js` | 画面操作・保存・一括作成・書き出し |
| `data/samples.js` | 見本カード(モンスター3枚・魔法1枚・罠1枚) |
