# 社内トレカ 入力フォーマット

`member_card_maker/index.html` をブラウザで開くと使えます(サーバー不要。GitHub Pages ならそのまま公開可)。
モンスター・魔法・罠カードを、1枚ずつでも、表(Excel)からまとめてでも作れます。

## 必要な情報

**最低限は「カード種類」と「元ネタ」の2つだけ。** 残りはAIが考えます。

| 区分 | 項目 | 何を書くか |
|---|---|---|
| 必須 | カード種類 | 効果モンスター / 通常・融合・儀式・シンクロ・エクシーズモンスター / 魔法カード / 罠カード |
| 必須 | 元ネタ | モデルになる人の名前、社内用語、出来事、商品・案件など |
| あると面白くなる | 口癖・名ゼリフ / エピソード / 一緒に登場させたい人・モノ | 効果テキストのネタ。カード同士をつなげたいときは他のカード名を「」で書く |
| 人のとき | 部署 / 役職・担当 / 特徴・得意なこと | 二つ名・種族・ATK/DEF を考える材料 |
| 魔法・罠のとき | 魔法・罠の種類 | 魔法: 通常/永続/装備/速攻/フィールド/儀式、罠: 通常/永続/カウンター(空欄なら通常) |
| 決めたい場合だけ | カード名 / 属性 / レベル / 種族 / 効果テキスト / ATK / DEF | 書いた項目はそのまま使い、空欄の項目だけAIが合わせて考える |
| 任意 | カードコード / イラスト画像ファイル名 / イラストの光 / 雰囲気 | カードコードは空欄なら WB-001 から連番 |

### どんなカードにするか(元ネタの例)

| カード種類 | 向いている元ネタ | 例 |
|---|---|---|
| 効果モンスター | 社員(1人1枚) | 財務統括魔導士スズキ |
| 融合・シンクロ・エクシーズ | 名コンビ、チーム、部署 | 「スズキ」＋「ヨナハ」の財務税務タッグ |
| 魔法カード | 社内用語、決め台詞、便利な道具、イベント | 法務確認(速攻)、月末締め(フィールド)、電卓(装備) |
| 罠カード | 相手を止める・跳ね返す出来事 | リターン請求(カウンター)、稟議差し戻し(永続) |

### 世界観メモ(おすすめ)

ウィーブレインの社内用語・人物・出来事を「用語 / 種類 / 説明」で書いておくと、**すべてのカードのAI生成で使われ**、
カード同士の効果が「グレー金融」「法務確認」のようにつながります。
画面の「表からまとめて作る → ウィーブレインの世界観メモ」か、Excel テンプレートの「世界観メモ」シートに書きます。

## まとめて作る(Excel)

1. 画面の「📋 表からまとめて作る」から [入力テンプレート](templates/card_input_template.xlsx) をダウンロード
2. 「カード一覧」シートに1行1枚で書く(黄色の列=必須、青の列=空欄ならAI、灰色=任意。4〜9行目は例)
   - 効果テキストの改行はセル内改行(Alt+Enter)。「①：」で始めると2行目以降が字下げされる
3. 「世界観メモ」シートに社内用語を書く(任意)
4. 画面で「表ファイル」にそのExcelを選ぶ。イラスト画像があれば「イラスト画像」で複数選ぶと、
   「イラスト画像ファイル名」列と同じ名前の画像が自動で入る
5. 「空欄をAIでまとめて埋める」(Claude APIキーが必要)
   - キーがない場合: 「表を埋めてもらうチャットAI用プロンプトをコピー」→ ChatGPT / Claude に貼り、続けて表を貼る →
     返ってきた表を「貼り付けた表を読み込む」へ
6. 一覧から1枚ずつ確認・修正して「全カードをPNG保存」

CSV(UTF-8)やスプレッドシートからのコピー&ペースト(見出し行ごと)でも読み込めます。列の順番は自由で、見出しの名前で判定します。
「全カードを表(CSV)で書き出す」で今のカードを同じ形式の表に戻せます。

## 1枚ずつ作る

1. **① 元ネタ**でカード種類を選び、元ネタ・口癖・エピソードなどを入れる
2. **AIでカード文面を作る**(キーがなければ「チャットAI用プロンプトをコピー」→ 返ってきた JSON を貼って反映)
3. **③ イラスト**に写真や画像を入れる。「画像生成AI用プロンプト」をコピーして画像生成AIに渡すと、枠・文字なしのイラストが作れる
   - 枠つきの完成トレカ画像を入れたときは「トレカ画像からイラスト部分だけ使う」
4. **PNGで保存**(2048×2880px)

カードはブラウザに自動保存されます。別のPCへ移すときやチームで共有するときは「全カードをJSON保存」→「JSON読み込み」(世界観メモも一緒に保存されます)。

## JSON の項目(開発者向け)

1枚のカードは次の JSON です(「⑤ その他 → このカードのJSON」で確認・直接編集できます)。
複数枚まとめて読み込むときは `{"formatVersion": 1, "world": "世界観メモ", "cards": [ ... ]}` か配列にします。

```json
{
  "formatVersion": 1,
  "cardType": "spell",
  "subtype": "速攻",
  "name": "法務確認",
  "attribute": "魔",
  "customAttribute": { "text": "", "color": "#c6352a", "image": null },
  "level": 0,
  "tribe": "",
  "abilities": "",
  "effect": "①：相手が「グレー金融」を発動した時に発動できる。その発動を無効にし、自分はデッキから１枚ドローする。",
  "atk": "0",
  "def": "0",
  "cardCode": "WBSP-001",
  "copyright": "©2024 WB ARGO",
  "frameColor": "",
  "nameColor": "gold",
  "art": { "image": null, "zoom": 1, "x": 0, "y": 0, "effect": "blue", "intensity": 0.7, "fileName": "" },
  "member": {
    "realName": "法務チェック",
    "department": "",
    "role": "",
    "skills": "契約の穴を一瞬で見抜く",
    "personality": "",
    "episode": "スズキの得意技",
    "related": "「財務統括魔導士スズキ」",
    "tone": "かっこよく"
  },
  "autoFields": []
}
```

| 項目 | 内容 | 値 |
|---|---|---|
| `cardType` | カード種類(枠の色が変わる) | `normal` 通常 / `effect` 効果 / `ritual` 儀式 / `fusion` 融合 / `synchro` シンクロ / `xyz` エクシーズ / `spell` 魔法 / `trap` 罠 |
| `subtype` | 魔法・罠の種類(【魔法カード】の横のアイコン) | 魔法: `通常` `永続` `装備` `速攻` `フィールド` `儀式`、罠: `通常` `永続` `カウンター` |
| `name` | カード名。長いと自動で横に縮む | 文字列 |
| `attribute` | 右上の属性マーク | `光` `闇` `炎` `水` `風` `地` `神` `魔` `罠` `custom` |
| `customAttribute` | `attribute: "custom"` のときの中身。`image` に国旗などの画像を入れると画像が優先 | `text` 1〜2字 / `color` / `image` |
| `level` | 星の数(エクシーズは左から並ぶ)。魔法・罠では無視 | 0〜12 |
| `tribe` / `abilities` | 種族行「【CFO族／効果】」。`abilities` が空ならカード種類から自動 | 文字列 |
| `effect` | 効果テキスト。改行で段落、`①：` で始まる行はぶら下げ字下げ、`---` だけの行は区切り線。長いと自動で縮む | 文字列 |
| `atk` / `def` | 攻撃力・守備力。`?` も可。魔法・罠では無視 | 文字列 |
| `cardCode` / `copyright` | イラスト右下の番号 / 一番下の表記 | 文字列 |
| `frameColor` / `nameColor` | 枠の色の上書き / カード名の色 | `#rrggbb` / `gold` `white` `black` |
| `art` | イラストと位置(`x` `y` は枠の幅に対する割合)、光エフェクト、表から読み込んだときの画像ファイル名 | |
| `member` | AI が文面を考えるための元ネタ(カードには印刷されない) | `tone` は `かっこよく` `面白く` `かわいく` `渋く` |
| `autoFields` | 表から読み込んだとき空欄だった項目。「空欄をAIでまとめて埋める」でここだけ作られる | `name` `attribute` `level` `tribe` `effect` `atk` `def` |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `templates/card_input_template.xlsx` | まとめて作るための入力テンプレート(カード一覧・記入ガイド・世界観メモ) |
| `js/card_format.js` | 上記フォーマットの定義・正規化、表の読み書き、AI向けプロンプト |
| `js/card_renderer.js` | JSON → canvas への描画(枠・星・属性・魔法罠アイコン・イラスト・テキスト組版) |
| `js/ai.js` | Claude API 呼び出し(キーはブラウザ内のみに保存) |
| `js/app.js` | 画面操作・保存・一括作成・書き出し |
| `js/vendor/xlsx.mini.min.js` | Excel 読み込み(SheetJS、Apache-2.0) |
| `data/samples.js` | 見本カード(モンスター3枚・魔法1枚・罠1枚) |
